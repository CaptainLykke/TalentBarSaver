TalentBarSaver 0.1.0  (WotLK 3.3.5a)
=====================================
Talented (Talent-Templates) + Action Bar Saver 2 (Leisten-Profile) in einem Addon.
Die Aktionsleisten wechseln automatisch mit dem Spec.


INSTALLATION
------------
1. WoW komplett beenden.
2. Ordner "TalentBarSaver" nach  <WoW>\Interface\AddOns\  kopieren.
3. Die alten Ordner "Talented" und "ActionBarSaver" aus  Interface\AddOns  herausnehmen
   (z. B. auf den Desktop verschieben). Laufen sie parallel, gibt es Lua-Fehler.
4. Alte Daten uebernehmen (Templates + Profile), siehe unten.
5. WoW starten, /tbs eingeben.


ALTE DATEN UEBERNEHMEN
----------------------
WoW speichert Daten pro Addon-Ordner in:
  <WoW>\WTF\Account\<ACCOUNTNAME>\SavedVariables\

Die zwei alten Dateien einfach zu einer neuen zusammenfuegen (WoW muss dabei beendet sein):
  Talented.lua + ActionBarSaver.lua  ->  TalentBarSaver.lua

PowerShell (im SavedVariables-Ordner ausfuehren):
  Get-Content .\Talented.lua, .\ActionBarSaver.lua | Set-Content .\TalentBarSaver.lua

Die alten Dateien kannst du als Sicherung liegen lassen.


BEDIENUNG
---------
/tbs              Fenster oeffnen/schliessen (/abs ohne Argument geht auch)
/tbs save <name>  aktuelle Leisten speichern       (alle alten /abs-Befehle funktionieren weiter)
/tbs help         alle Befehle
/talented         Talented-Optionen

Fenster, Reiter "Zuordnung":
- Pro Talented-Template ein Profil auswaehlen (z. B. "Ret PvE" -> ret-pve).
- Fallback pro Talentbaum (greift, wenn kein zugeordnetes Template zum Spec passt).
- "Jetzt anwenden" laedt sofort das passende Profil.

Wann wird automatisch gewechselt?
- Nachdem Talented ein Template erfolgreich angewendet hat.
- Beim Dual-Spec-Wechsel: zuletzt angewendetes Template dieser Gruppe
  (wenn dessen Hauptbaum noch zum Spec passt), sonst Fallback nach Talentbaum.
- Geladen wird ca. 1 Sekunde spaeter (neue Talentzauber muessen erst im Zauberbuch sein).
- Im Kampf wird nichts geladen, sondern nach dem Kampf nachgeholt.

--------------

Neue Dateien in der .toc unter "# Eigene Erweiterungen" eintragen.
